# IBSLPROJECT
Peer Tutoring Coordinator

Problem: Manually matching student tutors with students based on subject needs, mutual free periods, and grade levels takes hours of spreadsheet filtering each week.

Computational Solution: A program that tajkes tutor/student profile data and runs a matching algorithm to generate optimal pairings while logging past session histories.
